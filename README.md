**# Online Bookstore Analysis Dashboard**

**Project Overview**

This project analyzes online bookstore sales using Python, Pandas, and Power BI.

The objective was to identify revenue trends, top customers, best-selling books, and product category performance.

**Dataset**

The analysis was performed using three datasets:
- Books
- Customers
- Orders

The datasets were merged using **Customer_ID** and **Book_ID** to create a consolidated analytical dataset.

**Tools Used**
- Python
- Pandas
- Power BI
- GitHub

**Key Analysis Performed**
- Data Cleaning
- Data Validation
- Dataset Merging (Joins)
- Feature Engineering
- Revenue Analysis
- Customer Analysis
- Product Analysis
- Time-Series Analysis

**Dashboard KPIs**
- Total Revenue: **$75.63K**
- Total Orders: **500**
- Total Customers: **307**
- Average Order Value: **$151.26**

**Key Insights**
- Romance generated the highest revenue (**$13,068.98**).
- Expensive books contributed **53.5%** of total revenue.
- The top customer generated **$1,398.90** in revenue.
- Sales increased significantly in **2024** compared to **2022**.
